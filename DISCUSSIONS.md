# KROTAL — GitHub Discussions Setup

This file documents the discussion categories to create, their slugs, and
seed topics to kick-start the forum.

## 1. Categories to create

GitHub Discussions has no default "topic" concept beyond categories. Create
these **categories** (Settings → Discussions → "New category"). The slug is
auto-generated from the name — keep the names below so the site's links match.

| # | Name                  | Emoji | Slug (link in site)      | Format      |
|---|-----------------------|-------|--------------------------|-------------|
| 1 | Announcements         | 📣    | `announcements`          | Announcement|
| 2 | General Support       | 🙏    | `q-a`                    | Q&A         |
| 3 | Centurion · PKG_A     | 🎖️    | `centurion`              | General     |
| 4 | Kopier · PKG_B        | 🔁    | `kopier`                 | General     |
| 5 | Krowd · PKG_C         | 👥    | `krowd`                  | General     |
| 6 | Challenge Strategy    | 🧭    | `strategy`               | General     |
| 7 | Troubleshooting       | ⚠️    | `troubleshooting`        | General     |
| 8 | Ideas & Feedback      | 💡    | `ideas`                  | Idea        |

> Note: the "General Support" category reuses the built-in `q-a` slug so the
> existing link works. You can rename the built-in "Q&A" category to
> "General Support" instead of creating a new one — either way keep slug `q-a`.

## 2. Seed discussion topics (paste these in to populate the forum)

   packages (Centurion / Kopier / Krowd), crypto-only billing (BTC, ETH, SOL,
   USDT), and FTMO 200K 3-step focus.
